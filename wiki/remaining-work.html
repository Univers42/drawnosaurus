How to work an item

  1. Branch from develop as feature/<topic> or fix/<topic>. Engine work gets a branch of the same name in engine/ and a submodule bump in the root.
  2. Read the oracle first. make oracle checks Excalidraw out at the pin into third_party/excalidraw. Cite what you port as path@1118751f:lines.
  3. Red first. Write the failing test, then the code. Unit tests target the .ts modules beside DrawSurface.svelte; engine behaviour gets a tests/ci_*.rs; anything a person does with a mouse or keyboard gets an e2e/*.spec.ts.
  4. Update the registry. In packages/conformance/src/registry.ts, turn the matching rules from gap to covered and name the new test files. Split a half-done rule; never overclaim.
  5. Run the gates yourself. Engine make quality (set COMPOSE_PROJECT_NAME per worktree), then make wasm, make quality, make conformance, make test-integration and the full Playwright suite. Warnings are errors.
  6. Release. Engine branch, engine develop, engine main, each with the engine CI green. Then root develop with CI green, then root main with main's own CI run green. Rebuild the main checkout: make wasm, make up, and make stale must say current.

Sizes: S is under a day, M a few days, L a week or more.

Export and files

35 linesL

The most visible gap for anyone who shares a board.

2.1

Whole-scene PNG

engine.exportPng() (engine/src/engine.ts:801-803) is canvas.toBlob() of the visible canvas, so whatever is scrolled out of view is cut off. Render into an offscreen canvas framed by the scene's bounds (the contract's bounds.ts already mirrors the engine), at 1×, 2× or 3×, with or without the background. This fixes bug 0.1.

oracle packages/excalidraw/scene/export.ts:180-460 (exportToCanvas, exportToSvg)

2.2

Export the selection, or one frame

For PNG and SVG. Nothing threads the selection into either path today.

2.3

Copy as PNG and as SVG

SVG export exists (export/svg.rs, ci_export.rs); it only needs the clipboard plumbing. Rich external paste (from Google Docs, paste as one element) belongs here too.

2.4

Round trip

Embed the scene JSON in the PNG (a tEXt chunk) and in the SVG's metadata, so dropping the file back on the board restores it.

oracle packages/excalidraw/data/image.ts

2.5

Background and theme

SVG always paints a background rect (scene_to_svg). Add the option to leave it out, a background colour, and a dark-theme export. Collaborator colours are not themed either.

2.6

Fonts in SVG

export/svg.rs:416,423 names the font family but embeds no @font-face, so an SVG opened elsewhere falls back to a system font.

2.7

.excalidraw import and export

elements_from_json (export/json.rs:27-29) refuses anything whose type is not "osidraw". Map Excalidraw's schema both ways; a figure exports as a closed line.

oracle packages/excalidraw/data/json.ts, data/restore.ts

2.8

Crash recovery

Autosave falls back to a localStorage draft only. Add an IndexedDB store and a recovery prompt.

Done when the export specs cover each option, and the §31, §32, §39, “Export tricks”, “Files” and “Clipboard tricks” rules flip.

Selection and frames

11 linesM
  • Alt+click deep select reaches an element underneath another, and Alt while box-selecting does the same. Hit testing returns the topmost hit only.
  • Subtractive lasso. LassoMode is Contain or Intersect (selection/lasso.rs:29-35); add a remove modifier.

Images

  • Replace image, and a broken-image state.

Collaboration and modes

6 linesM
  • Follow any collaborator, outside presentation mode too. DrawFollowNotice renders only for a presenting peer, and following tracks slides, not the presenter's live camera (docs/reference/presentation.md:93-94).
  • Show each person's active tool in presence.

Engine architecture

47 linesL

None of this is visible to a user by itself, but the named-action layer makes every later shortcut, menu entry and palette command cheaper.

13.1

Named actions §28 · 25 lines

commandPalette.ts is a tested Command[] registry, but onAppShortcut (DrawSurface.svelte:1614) and the menus call the engine on their own. Make one action table that shortcuts, menus, the palette and buttons all dispatch through.

oracle packages/excalidraw/actions/register.ts, actions/types.ts

13.2

Performance budgets §49 · 10 lines

Criterion benches exist (engine/crates/draw-engine/benches/{editing,render,text}.rs, make bench) but only report. A gate would read target/criterion/*/estimates.json against checked-in thresholds, in its own CI job. Also: the drag-into-frame history step still keeps two id lists (docs/reference/zorder.md:99-101).

13.3

Transactions §29 · 4 lines

A commit is one stamp at the end of a gesture (push_history). There is no start, update, commit or cancel API.

13.4

Geometry and element model

No vector, matrix or circle types and no convexity test (§44). The element has no customData, library membership or explicit visibility, and nothing models a view-only state (§1).

13.5

Vectorize's production build

CI builds the web image but never runs it, and the browser suite runs vite dev, so nothing checks the production worker bundle. No checklist line; it is a blind spot.

14

Test harness work

22 linesM

Built, but these tests need a harness before they are cheap.

  • What gets painted (§42, 6 lines). Snap guides, binding highlights, frame clips, peer cursors and hover are drawn (wasm/paint.rs), but only the state they read is asserted. Needs a way to read back the paint, such as recording the canvas calls.
  • An accessibility audit (§48, 5 lines): focus management, dialog focus traps, screen-reader labels, high contrast, reduced motion. An automated audit (axe-core in Playwright, for example) is a new dev dependency; agree on it first.
  • The modifier matrix (§51, 8 lines): each tool against Shift, Alt, Ctrl and their pairs, as one table-driven spec.
  • Host state (§1, 3 lines): modal, sidebar and collaboration state held in Svelte.

Not planned

Different on purpose

  • The board lives on the server and merges per element; .osidraw files are an export, not the source of truth. appState is not persisted, and pictures live on the element until milestone 8 moves them.
  • A marquee selects what it contains, never what it only clips, so a small drag across a large background shape leaves it alone.
  • Select All includes locked elements so the context menu can unlock them; Excalidraw skips them.
  • Alt+Arrow moves between flowchart nodes.
  • Font preloading loads the Latin shard only; other scripts are laid out again when their shard arrives (fonts.ts:178-179). Revisit only if a non-Latin board visibly flickers.

Not ours to build

  • Bold, italic and letter spacing: Excalidraw has none either (the three open lines left out of the roadmap).
  • The cheat sheet's I for images and its Ctrl+Shift+]/[ are wrong; the oracle's own bindings are used.
  • Hosted AI (text to diagram, wireframe to code).
  • A File/Edit/View menu bar, which Excalidraw does not have either.

import { readChecklists } from "/app/packages/conformance/src/checklist.ts";

process.stdout.write(JSON.stringify(out));
