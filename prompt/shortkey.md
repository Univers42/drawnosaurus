# Excalidraw — Shortcuts & Hidden Features Cheat Sheet

> `Ctrl` = Windows/Linux
> `Cmd` = macOS
> `Alt` = Windows/Linux
> `Option` = macOS
>
> Tip: press `?` inside Excalidraw to open the built-in shortcut reference.

---

## ⚡ Essential shortcuts

- [ ] `V` — Selection tool
- [ ] `R` — Rectangle
- [ ] `D` — Diamond
- [ ] `O` — Ellipse / circle
- [ ] `A` — Arrow
- [ ] `L` — Line
- [ ] `P` — Pen / freehand drawing
- [ ] `T` — Text
- [ ] `N` — Sticky note
- [ ] `E` — Eraser
- [ ] `H` — Hand / canvas panning
- [ ] `F` — Frame
- [ ] `K` — Laser pointer
- [ ] `I` — Image
- [ ] `X` — Freehand drawing
- [ ] `?` — Open keyboard shortcuts / Help

> Note: tool shortcuts are letter-based and current versions made them
> CapsLock-insensitive; `Shift+letter` no longer switches tools.

## 🧭 Navigation & canvas

- [ ] `Space + drag` — Pan the canvas
- [ ] `Middle mouse + drag` — Pan the canvas
- [ ] `Mouse wheel` — Scroll/pan
- [ ] `Ctrl/Cmd + mouse wheel` — Zoom
- [ ] `Ctrl/Cmd + +` — Zoom in
- [ ] `Ctrl/Cmd + -` — Zoom out
- [ ] `Ctrl/Cmd + 0` — Reset zoom
- [ ] `Shift + 1` — Zoom to fit / content
- [ ] `Shift + 2` — Zoom to selection
- [ ] `Shift + 3` — Zoom to fit / viewport mode
- [ ] `Page Up` — Move/pan page upward
- [ ] `Page Down` — Move/pan page downward
- [ ] `Shift + Page Up` — Move/pan page left
- [ ] `Shift + Page Down` — Move/pan page right

## ✏️ Drawing modifiers

### Shapes

- [ ] `Shift + drag` — Constrain proportions / geometry
- [ ] `Alt/Option + drag` — Draw/resize from the center
- [ ] `Shift + Alt/Option + drag` — Center + constrained proportions
- [ ] `Shift` while drawing — Lock angle / constrain geometry
- [ ] `Ctrl/Cmd` while snapping — Temporarily disable snapping

### Lines & arrows

- [ ] `Shift` while drawing — Lock the angle
- [ ] `Click` repeatedly — Create multi-point line/arrow
- [ ] `Double-click` / finish shortcut — Finish multi-point line/arrow
- [ ] `Press arrow shortcut again` — Cycle/change arrow type
- [ ] `Ctrl/Cmd` while creating an arrow — Prevent automatic binding
- [ ] `Alt/Option` when binding — Bind at a fixed point instead of the normal
      automatic binding position
- [ ] `Drag` instead of click-click — Quickly create a single straight segment
- [ ] `Double-click arrow` — Edit its points
- [ ] `Click midpoint` — Add/edit a line/arrow segment
- [ ] `Delete` selected point — Remove a line/arrow point
